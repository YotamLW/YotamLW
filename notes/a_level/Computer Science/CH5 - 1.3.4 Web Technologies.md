#Computer-Science 

## - HTML 

Hypertext Markup Language 
Declares & defines structure and contents of a web page 
Uses tags <> 

`<html> </html>` - needs to open and close all HTML code 
`<link rel="stylesheet" href="style.css">` - external CSS file 
`<title> </title>` - text displayed in tab 
`<head> </head>` - contains link and title tags (information to set up the page) 
`<body> </body>` - contains rest of tags 
`<h1> </h1> <h2> </h2> <h3> </h3>` - headings 
`<p> </p>` - text 
`<a href="https://www.google.com"> </a>` - contained text turns into link 
`<img src="image.png" alt="This is an image" width="100" height="100">` - image 
`<div> </div>` - used to separate elements 
`<ol> </ol>` - ordered list 
`<ul> </ul>` - unordered list 
`<li> </li>` - list element 
`<script> </script>` - contains JavaScript 
`<form> </form>` - creates a form 
`<input type="text" name="username">` - text input box 
`<input type="submit">` - submit box 

Use style in-line e.g. `<p style="color: red; font-size: 50px"> Text </p>` 

## - CSS 

Cascading Style Sheets 
Declares visual style / appearance of web page 
Uses selectors e.g. classes, IDs 
Every line should end in a semi-colon 

`color` - changes element colour 
`background-color` - changes colour behind an element 
`border-color` - changes colour of border 
`border-style` - type of border (solid, dashed, dotted) 
`border-width` - width of border (e.g. 10px) 
`font-family` - type of font (e.g. Arial) 
`font-size` - size of font (e.g. 30px) 
`height` and `width` change dimensions of element 

Colours can be entered in words, RGB or hex : 
`color: rgb(255, 0, 0);` or `color: red;` or `color: #ff0000` 

All elements of specific tag : `tag {}` 
Elements of class : `.class {}` 
Element with id : `#id {}`

## - Indexing 

Indexing is when web pages are added to an index 
This is done by web crawlers that follow links to different pages 
Pages are indexed including relevant information e.g. age, meta tags, keywords 
Pages are then ranked on the search engine using an algorithm such as PageRank : 
$$
PR(A) = (1-d) + d \left( \sum^n_i \frac{PR(i)}{L(i)} \right) 
$$
$PR(i)$ is the PageRank of page $i$ 
$L(i)$ is the number of outgoing links of page $i$ 
$d$ is the damping factor 
The damping factor is the probability of a user following a link 
This models browsing behaviour, creates fairness and prevents endless loops

Factors affecting a page's PageRank : 
- Number of inbound links ($\sum$) 
- PageRank of inbound links ($PR(i)$) 
- Number of other links from those pages ($L(i)$) 
Other factors include recency, age, meta tags, domain name, title, relevant tags / keywords etc.
