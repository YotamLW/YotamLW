#Computer-Science 

## - Development Models 

**Waterfall** : 
- Gather all requirements at the start 
- Everything designed carefully 
- Focus on initial requirements 
- Formal and documented stages 
- Linear stages : Analysis > Design > Development > Testing 
- Not very flexible 
- Little communication / interaction with clients 
- Best for very small specific projects, training projects, all features known 

**Spiral** : 
- Gather fewer requirements at the start 
- More Iterative & experimental design 
- Focus on management and planning 
- More client feedback at each iteration 
- Some projects may not be finished if no longer deemed useful or there is high risk 
- Four quadrants : 
	- Determine objectives 
	- Identify & manage risk 
	- Develop & test 
	- Plan next iteration 

**Agile** : 
- Similar to spiral but more focus on frequent releases 
- Very iterative and experimental designs 
- Flexible to client requirement changes & feedback 
- Best for web-based projects 
- **XP** : 
	- Type of Agile 
	- Regular automated tests 
	- Pair programming 
	- Code reviews 
	- Better for higher quality code 
- **RAD** : 
	- Type of Agile 
	- Focus on prototype versions 
	- Regular feedback from clients 
	- Focus on good-enough within time constrictions 

## - Reading OCR code 

For global variables write `global something = 1` 
Variables can be typecast e.g. `str(3)` returns `"3"` 
`do until` loops do first then check if to do again 
`a MOD b` is the same as `a % b` in JavaScript 
`a DIV b` is the same as `Math.floor(a / b)` in JavaScript 
`array[0,0]` is the same as `array[0][0]` in JavaScript 
`variable = input("")` to allow input 
`for i=0 to 9 ... next i` to make for loops 
`switch: case: num < 1 print("less") case: num > 1 print("more") default: print("1")` 
`string.substring(start, length)` will give substring
