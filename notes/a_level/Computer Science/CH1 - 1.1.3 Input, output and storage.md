#Computer-Science 

## - Input & Output Devices 

Input Devices : 
- Keyboard - Enter text to a computer 
- Touchscreen - Touch input to a device 
- Camera - collect visual data 
- Heat sensor - Detect changes in temperature 
- Accelerometer - Detects changes in speed 
- Barcode readers - Reads barcodes 

Output Devices : 
- Monitor - Provide visual output 
- Speaker - Provide auditory output 
- Printer - Convert data into something 3 dimensional 
- Actuator - Provide a mechanical output for a machine 

## - Storage Devices 

Storage Devices are secondary storage 
There are 3 types of storage devices - Magnetic, Optical and Flash 

A Hard Disk is a **Magnetic** storage device 
Made up of multiple metal discs rotating very fast 
A drive head polarises parts of the disc representing binary 
Often have a large capacity and are cheaper 
Harder to transport and more vulnerable to damage 
Slow & Loud 

An Optical disk is an **Optical** storage device 
Patterns are burned onto a CD that represent data 
Laser passes over reflective CD to read data 
Very cheap to make and transport / distribute 
Can be damaged easily and has low capacity 

A Solid-State Disk (SSD) is a **Flash** storage device 
Flash memory cells hold data 
All electric so much more energy efficient 
Less prone to damage / corruption 
Fast 
More expensive 

## - ROM & RAM 

**Random Access Memory** (RAM) : 
- Main memory / primary storage 
- Readable and Writable 
- Volatile (data lost upon power loss) 
- Stores currently running programs 
- Often larger than ROM 

**Read Only Memory** (ROM) : 
- Primary / Secondary storage 
- Only readable 
- Persistent (retains memory) 
- Stores BIOS (checks hardware) & bootstrap (loads & activates OS) 
- Useful for embedded systems 

ROM is used to load OS and check hardware for general purpose computers & mobile devices 
ROM is often the prominent storage in embedded systems that should not be changed 
ROM may be rewritable for firmware updates (e.g. OS updates) 

## - Virtual Storage 

Virtual Storage is storage that is physically located elsewhere but is simulated to be local 
This means a user can outsource storage hardware and access it online 
Allows for scalable storage requirements 
Compromises on level of control 

Examples : OneDrive, Google Drive, Dropbox 
Easier for user to access from multiple devices and useful for backup 
Saves expenses for businesses on hardware and IT staff 
Providers can make money
