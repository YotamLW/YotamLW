#Computer-Science 

## - Function of OS 

The operating system is a set of programs that manage the operation of a computer 
An operating system provides : 
- Memory Management 
- Interrupt Handling 
- Processor Scheduling 
- Managing Inputs & Outputs 
- Security & Access control 
- Providing a User Interface 
- Providing utility software 

## - Memory Management 

Paging is when memory is divided into files of fixed size 
This can help map logical structure to physical structure of memory 

Segmentation is when memory is divided into files of variable size 
This can help by having a single program occupy a single segment 

Virtual Memory is when secondary storage is used as memory 
This occurs when main memory is full 
Pages are swapped between main memory and secondary storage 
This is much slower so will impact the computer's performance 
When main memory is full, unused programs in main memory can be swapped to secondary storage to make room for new programs 

## - Interrupts 

An Interrupt is a signal from a program or hardware to the OS 
Interrupts enable multi-tasking 
An interrupt may be called when an application closes or a user provides input through hardware 

Interrupt Service Routine : 
1) Suspends running program & disables lower priority interrupts 
2) Puts contents of registers onto system stack in memory 
3) Interrupt Executed by loading value to PC 
4) Contents of registers popped and reapplied from system stack 
5) Lower priority interrupts / programs resumed 

## - Processor Scheduling 

OS needs to allocate processor time to different tasks 
Processor Scheduling enables multi-tasking as many tasks can run in turns 
Fair use in multi-user system and maximises hardware efficiency 

Scheduling Algorithms : 
First Come First Serve (FCFS) : 
- Jobs processed in order of arrival 
- Easy to implement 
- Long tasks will hinder processor and stop other tasks 
Shortest Remaining Time : 
- Shortest estimated completion time run first 
- More tasks completed 
- Can prevent long processes from being run 
Shortest Job First : 
- Shortest estimated running time run first 
- More tasks completed 
- Can prevent long processes from being run 
Round Robin : 
- Each task receives equal time slice and tasks cycle around 
- Fair to all tasks and tasks not blocked 
- Tasks may take longer to fully complete 
Multi-level feedback queue : 
- Algorithms to maximise processor use & efficiency by incorporating all methods 
- Hardware and time efficient 
- Requires complex algorithms 

## - Types of OS 

Distributed - across multiple computers e.g. school system 
Embedded - specific purpose & low resources & ROM e.g. washing machine 
Multi-tasking - user can switch between tasks e.g. personal computer 
Multi-user - multiple users at the same time e.g. server 
Real-time - tasks completed quickly and consistently and can handle many inputs and have many failsafe features and redundancy e.g. airplane & databases 

## - BIOS and drivers 

BIOS : 
- Stored in ROM 
- Runs on computer bootup 
- Tests hardware / components 
- Loads bootloader from secondary storage 
- Bootloader loads the OS 

Drivers provide software interface to hardware 
Hardware and OS specific 
Drivers can be downloaded and installed onto the OS 

A Virtual Machine is software that simulates the function of a machine 
Useful for emulating hardware or testing potentially malicious programs 
Enables testing of programs on multiple type of OS 
No need to get new software for different CPU architectures 
e.g. used by Java to convert to bytecode
