#Computer-Science 

Concurrency is when multiple tasks are done during the same time frame (e.g. multitasking OS) 
Parallelism is when two tasks are being done simultaneously (e.g. multicore computers) 
Parallel tasks are concurrent but concurrent tasks may not be parallel 

Concurrent processing : 
- Processes happen at the same time / overlap 
- One process can start before another finishes 

Benefits of concurrent processing : 
- More efficient processor use as less idle time 
- Long running tasks do not delay shorter ones 
- Can run other tasks while waiting on memory for a specific task 
- User can interact with computer while other tasks are running 

Downsides of concurrent processing : 
- More complex so less consistent operation 
- Difficult to debug
