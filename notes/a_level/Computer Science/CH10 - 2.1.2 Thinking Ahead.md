#Computer-Science 

Thinking ahead is : 
- Working out what the inputs and outputs are 
- What needs to be included in the final solution 
- Consider caching 

Need to know preconditions before producing a solution 

Moving data between components takes time and processing takes time 
Caching can reduce time taken to move data between components 
Trades memory for time 
Not useful if : 
- Limited space / memory 
- Data is random in terms of time and location 
- More cache misses than cache hits 
- Cached data is unlikely to be needed again 
A drawback is more complicated program design to make use of it 

Use of reusable program components in programs : 
- A piece of code can be reused many times to improve efficiency 
- Less time to plan, design and code the program 
- Easier error detection, debugging and correction 
- Easier maintenance of program 
Reusable program components can be implemented by : 
- Using subroutines, procedures and functions 
- Using classes and class features 
- Using external libraries 

Theses concepts allow for : 
- Faster development 
- Faster and easier adaptation / maintenance 
- Better program performance 
The disadvantage is more time to design and make use of features
