## Simplifying Expressions 

Simplifying Boolean expressions is useful for optimising hardware & code 
When simplifying, AND has priority over OR 

Commutative - $X \land Y = Y \land X$ and $X \lor Y = Y \lor X$ 
Associative - $X \land (Y \land Z) = (X \land Y) \land Z$ and $X \lor (Y \lor Z) = (X \lor Y) \lor Z$ 
Absorption - $X \land (X \lor Y) = X$ and $X \lor (X \land Y) = X$ 
Double Negation - $X = ¬¬X$ 

To make simplification easier, can convert $\land$ into $\times$ and $\lor$ into + so : 
Commutative - $ab = ba$ and $a + b = b + a$
Associative - $a(bc) = (ab)c$ and $a + (b + c) = (a + b) + c$ 
Absorption - $a (a + b) = a$ and $a + (ab) = a$ 
Double Negation - $a = --a$ 

De Morgen's laws : 
$¬(A \lor B) = ¬A \land ¬B$ 
$¬(A \land B) = ¬A \lor ¬B$ 
e.g. $¬(¬A \land ¬B) = ¬(¬A) \lor ¬(¬B) = A \lor B$ 

Example : 
$Q = A \land B \lor A \land (B \lor C) \lor B \land (B \lor C)$ 
$= A \land B \lor A \land (B \lor C) \lor B$ using absorption 
$= A \land B \lor A \land B \lor A \land C \lor B$ by expanding brackets 
$= A \land B \lor A \land C \lor B$ using absorption 
$= A \land C \lor B$ using absorption 
so $Q = B \lor A \land C$

## Logic Circuits 

Flip-flop circuits are used to store the state of a bit 
These are used to store 1 bit of memory 
There is a data and clock input and there are 2 outputs 
Each time the clock input becomes 1, the flip-flop is toggled to the value of the data input
