## - Programming Paradigms 

**Procedural** : 
- Uses procedures and functions 
- Series of instructions one after the other 
- Simple, efficient and controlled 
- Harder to scale, limited code reusability 
- Smaller applications e.g. performance-critical systems 

**OOP** : 
- Uses objects and classes 
- Classes and objects are main building blocks 
- Modular, scalable, reusable and easily maintainable 
- Can be more complex to code 
- Large, complex systems e.g. company software or video games 

**Low-level** : 
- Machine code / Assembly code 
- Very simple and low-resource 
- Harder to perform complicated functions 
- Useful for small limited use applications e.g. factory parts code, washing machines 

**Procedural Programming features** : 
- Variables - identifiers with variable values 
- Constants - identifiers with fixed values 
- Selection - `if ... else` and `switch ... case` commands 
- Iteration - `for`, `while` and `do ... until` loops 
- Sequence - Lines are run one after the other 
- Subroutines - functions and procedures 
- String handling - `string.substring(start, end)`, `.split()`, `.join()` etc. 
- File handling : 
  - `file = openRead("fileName")` or `file = openWrite("fileName")` 
  - `if NOT file.endOfFile()` 
  - `file.readLine()` or `file.writeLine("Hello There")` 
  - `file.close()` 

**OOP features** : 
- An object is an instance of a class 
- To create an object, do `let dog = new Animal()` where Animal is a class 
- Declare attributes as private or public 
- Private means you cannot get an attribute by doing `object.attribute` 
- Create setter and getter methods to access and change object values from outside the object 
- An example of a class code : 
```
class Animal {

	private height 
	private weight

	new (pHeight, pWeight) {
		height = pHeight
		weight = pWeight
	}

	procedure grow () {
		height ++
		weight ++
	}

	function getHeight () {
		return height + "cm"
	}

	procedure setHeight (pHeight) {
		if (pHeight > 0) {
			height = pHeight
		}
	}

}
```
- **Inheritance** means subclasses inherit their superclass's methods & attributes 
- **Polymorphism** means different classes can have different versions of the same named method 
- **Encapsulation** means wrapping methods & attributes together, making private attributes accessible only through getters and setters, often called "information hiding" 
- **Abstraction** means hiding details and only showing essentials

## - LMC Language 

11 instructions : 
- `ADD a` - Add value at address a to accumulator 
- `SUB a` - Subtract value at address a from accumulator 
- `STA a` - Store accumulator at address a 
- `LDA a` - Copy value at address a to accumulator 
- `BRA a` - Loop to position a in the program 
- `BRZ a` - Same as BRA but only if accumulator = 0 
- `BRP a` - Same as BRA but only if accumulator $\ge$ 0 
- `INP` - Allows user input to accumulator 
- `OUT` - Outputs value of accumulator to user 
- `HLT` - Ends program 
- `a DAT 1` - Saves value 1 to address a 

## - Addressing Modes 

Immediate addressing : 
- Value is the data to be used for calculations 
- Useful for hard-coded instructions e.g. constants (e.g. $\pi$) or incrementing PC 
Direct Addressing : 
- Value is the address of the data to be used for the calculations 
- Useful for fixed addresses e.g. for static data structures 
- Useful for variables 
- Addressing mode used in LMC 
Indirect Addressing : 
- Value is the address that holds the address to the data to be used for calculations 
- Useful for unfixed addresses e.g. for dynamic data structures 
- Extends addressable range, not limited by operand size 
Indexed Addressing : 
- Value + Value in index register is the address of data to be used for calculations 
- Useful for iterating through arrays by incrementing index register
