#Computer-Science 
## - Instruction Set Computers 

**CISC**  (Complex Instruction Set Computers) : 
- Longer more complex instruction set built into hardware 
- Shorter more concise assembly language 
- Less work to compile code 
- Less RAM to store instructions 

**RISC** (Reduced Instruction Set Computers) : 
- Only simpler instructions as hardware 
- More registers available 
- One clock cycle instructions, easier to pipeline 
- More consistent execution time 
- More work for compiler and more RAM usage 

## - Graphical Processing Unit (GPU) 

A co-processor is a processor meant to supplement the CPU 
A GPU is a co-processor specially designed for SIMD (Single Instruction Multiple Data) 
Used for graphics rendering, processing Big Data, DNA sequencing, simulation models 
Multiple cores allow for a distributed workload 

GPU vs CPU : 
**GPU** : 
- Many simple cores 
- Very large parallel architecture 
- Similar repetitive tasks 
- Optimised for pipelining 
- Specialist Mathematical instructions e.g. matrix computations / ray tracing 
**CPU** : 
- Few Powerful cores 
- Not parallel architecture 
- Complex specific tasks 

## - Parallel Processing 

A parallel system is when multiple cores are run at the same time (in parallel) 
This is an easy way to improve performance through more simpler hardware 
Easier to scale than having one very powerful core 
The limitation is that software may not be coded to use parallel cores 
Parallel processing can be multiple cores in a processor or multiple processors in a computer 

Benefits of parallel processing : 
- Carry out FDE cycles faster 
- More instructions per second 
- Less waiting time for user 
- Good for optimal multi-tasking
