#Computer-Science 

Problem recognition is identifying that there is a problem to be solved and if it can be solved using computational methods 
Problem recognition starts with identifying inputs and outputs 
Problem decomposition is splitting down problems into sub-problems to be solved independently 
Other computational methods : 
- Abstraction 
- Divide and Conquer - decomposing a problem into smaller parts and solving each separately 
- Heuristics 
- Concurrency 
- Backtracking 
- Performance modelling 
- Data mining 

Features of problems that enable computational methods : 
- Involves calculations 
- Has inputs, outputs and processes 
- Involves logical reasoning 

Computational methods useful for : 
- Used to break a problem down into sections (relevant to context) 
- Models and simulations can be run 
- Algorithms can be used to do stuff 

Data mining is the processing of big data to extract useful information 
Searches through data to create patterns and calculate correlations 
Useful for finding trends for research 

A heuristic is using an educated guess approach leading to a good enough result 
In the A* algorithm the heuristic is an underestimate for the distance for each node to the end 
Used to speed up the process of finding the solution by identifying which paths to go to first 

Performance modelling is the testing / simulation of a system before its use 
Performance modelling is useful for : 
- Stress testing and testing response time e.g. lots of requests to a web server 
- Identifying and fixing bottlenecks 
- Plan required capacity / requirements 
- Identify effective use of caching 
Useful for events such as : 
- Launching online tickets 
- Brand new website / apps / services / games 

Pipelining is when the result of one process feeds into the next process
