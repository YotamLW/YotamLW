#Computer-Science 

A network is when 2+ devices are connected to communicate / share resources 
A protocol is a set of rules for network communications 
Standards are the rules 
Protocols ensure different devices follow the same standards to allow communication 
Protocol examples : HTTP, HTTPS, TCP, IP, FTP, SMTP etc. 

## - TCP/IP Stack 

![[1.3.3a]] 
**Application** : Uses protocols e.g. HTTP, HTTPS, TCP etc. (used by web browsers, web servers) 
**Transport** : Splits into packets and adds ports (used by operating systems) 
**Internet** : Adds IP addresses (used by routers, firewalls) 
**Link** : Adds MAC addresses (used by switches, WAPs) 
![[1.3.3b]] 

Layering enables : 
- Developers to work on different layers at the same time 
- Edit a layer without affecting others 
- Modularity and compatibility with programs from different developers 
Layering enables developers to work on different layers at the same time and edit a layer without affecting other layers 

Circuit Switching : 
- Direct link for entire connection 
- Data arrives in order 
- Pay for connection time 
- Reliable 
- e.g. old phone system 
Packet Switching : 
- Data split into packets 
- Packets can take different routes, decided at each node 
- May arrive out of order due to traffic 
- Packets need to be re-ordered at destination 
- Packets have headers and trailers to detect data loss / corruption and reorder them 
- Pay for amount of data transferred 
- Less reliable 
- More efficient use of a network 
- e.g. TCP/IP stack

## - DNS 

LAN (Local Area Network) : Group of devices connected over a small geographical area 
WAN (Wide Area Network) : Group of devices / LANS connected over a large geographical area and can often rely on 3rd party connections e.g. cables 
An IP address is made of 4 numbers between 0 and 255 that acts as a unique identifier for a device to be found on a network 

DNS (Domain Name System) : 
- Domain name extracted from URL 
- Domain name mapped to IP address 
- Resolvers / DNS servers hold a cache of commonly requested IP addresses 
- If not found request passes recursively to higher DNS servers e.g. TLD name server (.com, .org) 
- DNS server sends IP address to requesting source

## - Network Threats 

| Network Threats     | What it is                                                                | Minimisation / Prevention                    |
| ------------------- | ------------------------------------------------------------------------- | -------------------------------------------- |
| Hackers             | People who gain unauthorised access to devices                            | Secure Passwords & updated software          |
| Viruses             | Designed to damage a device's data / software and spread to other devices | Anti-Virus                                   |
| Unauthorised Access | Someone has unauthorised access to a private server / database            | Firewalls                                    |
| Denial of Service   | Many requests sent to a server causing it to slow down / stop responding  | Reduce ability to DoS e.g. hardware firewall |
| Spyware             | Software that secretly reads and transmits a devices activities           | Anti-Spyware                                 |
| SQL Injection       | Inputting a string that can be interpreted as an SQL query                | Secure code                                  |
| Phishing            | Sending fake fraudulent emails to try to trick users                      | Training                                     |
| Pharming            | Users redirected to fake websites to steal information                    | Training                                     |

## - Network Devices

| Network Device               | What it does                                     | How it does it                   |
| ---------------------------- | ------------------------------------------------ | -------------------------------- |
| Hub                          | Transmits data to all connected devices on a LAN | Wired or Wireless                |
| Switch                       | Transmits data to a specific device on a LAN     | Based on MAC addresses           |
| Router                       | Forwards packets between networks                | Assigns IP addresses to devices  |
| Modem                        | Changes signals between digital and analogue     | Machine                          |
| Cable / Ethernet             | Connects wired devices to network                | Wires                            |
| Wireless Access Point (WAP)  | Connects devices to a network without wires      | Transmits & receives radio waves |
| Network Interface Card (NIC) | Allows device to connect to a network            | Gives each device a MAC address  |
A firewall is an internet-layer software or hardware that monitors and filter traffic / packets going to and from a network 
Can also prevent unauthorised IP addresses and ports from being accessed 

## - Types of Network 

Client-Server Network : 
- Client device connects / sends a request to server 
- Server sends data back / responds to client 
- More expensive and harder to set up 
- Only one point of failure 
- Easy to back up 
- Easy to keep data more secure 
Peer-to-Peer Network : 
- Devices connect to each other 
- Devices send / recieve data to / from each other 
- Not expensive & easy to set up 
- No single point of failure 
- Can't control, may lead to piracy
