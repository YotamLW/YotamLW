#Computer-Science 

Abstraction is the removal of unnecessary details / components from a problem 
This simplifies complex problems which allows programmers to focus on core aspects of the program and minimise potential distractions 
Decomposition is the breaking down of a problem into smaller sub-problems 

Benefits of abstraction : 
- Reduces programming time 
- Reduces code complexity 
- Reduces required memory / computation power 
- Simplifies problem so it is easier to solve (e.g. mathematically) 
- Allows programmers to focus on core aspects of the program
