## - Compression 

Compression is the process of reducing a file's size to : 
- Take up less storage 
- Quicker transfer / download speed 
- Save money as less bandwidth usage 

Lossless : 
- No information is lost 
- Original data can be restored 
- Suitable for text where exact original letters are needed 
- Can be used for high value images 
- Often results in larger files than lossy 
Lossy : 
- Some information may be lost 
- Original data cannot be restored 
- Useful for photos or videos where exact bits matter less 
- Not suitable for text as exact bits matter 
- Can create smaller file sizes than lossless 

Run-length Encoding : 
- Lossless compression 
- Relies on consecutive data being the same 
- e.g. AAAABBCCC $\rightarrow$ 4A2B3C 
- Can result in larger files if not much consecutive data e.g. ABC $\rightarrow$ 1A1B1C 
- Suitable for screenshots with large areas of repeating colour 
- Not suitable for text or outside images 

Dictionary Coding : 
- Lossless compression 
- Relies on non consecutive repeating data 
- e.g. words being repeated in a text 
- Each word is given a simple token and the file is replaced by the tokens 
- The file is transmitted along with the dictionary 
- Suitable for compressing large text files e.g. books 

## - Encryption 

Encryption is when data is coded to prevent unwanted reading 
HTTPS is encrypted 

Symmetric Encryption : 
- Same key encrypts and decrypts the data 
- Both users have the same key 
- anyone with the key can encrypt & decrypt 

Asymmetric Encryption : 
- Each user has a public and private key 
- Anyone can access public key to encrypt data for the user 
- Only private key can decrypt data 

In reality, asymmetric encryption is used to agree on a symmetric key online 

## - Hashing 

Hashing is a consistent and irreversible function 
Maps variable length input to a fixed length output 
Collisions may occur where two inputs hash to the same output 

Methods of collision handling : 
- Linear probing - move through hash table one space at a time to find next free space 
- Chaining - each location is the start of a linked list, collision is added onto it 

Rainbow tables are lists of common hashes 
Salting (adding string to a password before hashing) can remove rainbow table threat 
Hashing can be used to store passwords without being readable 
When users log in their password is re-hashed and compared to the stored hash
