#Computer-Science 

A data structure is a collection / store of data types 
An abstract data type has a set of operations with no definition on how to implement them 

Static - fixed number of items 
Dynamic - variable number of items 
Immutable - items cannot change 
Mutable - items can change 

| Data Structure | Number of items | Changeable items | Data types |
| -------------- | --------------- | ---------------- | ---------- |
| Array          | Static          | Mutable          | Same       |
| Tuple          | Static          | Immutable        | Mixed      |
| List           | Dynamic         | Mutable          | Mixed      |
| Record         | Static          | Mutable          | Mixed      |
An array is an efficient way to store data in memory as it is a fixed size so data can be stored straight after it in memory 
Dynamic data structures may have less efficient memory allocation 

## Linked Lists 

A linked list is a list so is dynamic, mutable and can have different types of item 
Items have data and pointers that point to next item / node in the list 
Items do not need to be in order in memory 
Linked lists allow for priority queues 
Items can be removed from the list anywhere with no gaps 

To end list, pointer is -1 or null 
`headPointer` indicates the memory address of the first element in the list 
`nextFree` indicates next free memory address for a new item to be added into 

To add new item : 
- Store new item in address of `nextFree` 
- Follow list until wanted location 
- Change target item's pointer to previous item's pointer 
- Set previous item's pointer to `nextFree` 
- Set `nextFree` to this address' original pointer

To remove a target node : 
- Traverse list until the node before 
- Change pointer of the node before to the target node's pointer 
- Set target node's pointer to `nextFree` 
- Remove data and set `nextFree` to target node

## Queues 

First in First out data structure 
Used for task scheduling, breadth first search (BFS) 
Can be linear or circular 
Can enqueue and dequeue 

Linear Queue : 
- Empty if `tail == -1` 
- Full if `tail == list.length - 1` 
- To enqueue, check if full, increment tail, add data to address of tail 
- To dequeue, check if empty, store first item, shift all data down, decrement tail, return first item 

Circular Queue : 
- Empty if `list[head] == empty` 
- Full if `(tail + 1) MOD list.length == head` 

## Stacks 

Last in First out data structure 
Used for recursion, DFS, undo/redo, evaluating expressions, browser history 
Can push (adds), pop (removes & returns) & peek (returns) 

Empty if `top == -1` 
Full if `top == stack.length - 1` 
To push, check if full, increment top, add data to address of top 
To pop, check if empty, save top item, delete top item, decrement top, return saved item 
To peek, check if empty, return top item 

## Graphs 

Graphs have nodes connected by edges 
Graphs use symbols to represent locations and edges to represent connections 
Edges can be unidirectional, bidirectional, weighted or unweighted 
Graphs can be traversed (e.g. by web crawler to index pages) 
Adjacency lists and matrices show node connections in different ways

## Trees 

A graph which has a single root node, no cycles and edges are undirected 
Leaf nodes are nodes with no children 
Can be used for folder structure, hierarchical data, game moves 

Binary Search Tree (BST) : 
- Nodes must have 0 - 2 children 
- Elements need to be ordered (e.g. larger to the right, smaller to the left) 
- Quicker to search as data is sorted (O(logn) time complexity) 

To add a node, search tree to parent node, add node, give parent node a pointer to added node 

To delete a node, change parent node to point to child node then remove target node 

To traverse a tree draw an outline around it 
For pre-order, draw dots to the left of each node (Used for copying a tree) 
For in-order, draws dots below (Used for getting the tree data in order) 
For post-order, draw dots to the right (Used for deleting tree or for evaluating syntax tree) 
The order of dots on the outline is the order of traversal of the nodes 

Breadth first traversal - rows 
Depth first traversal - columns 

## Hash Table 

Used to store data in memory with quick access time 
Constant O(1) time complexity 
To add an item, hash it, MOD it by the size of the array, then store it 
If two items hash to the same location, use a linked list to chain to the next available slot 
A get method given a value will return the address of that value in memory
