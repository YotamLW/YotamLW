#Computer-Science 

Data Types : 
- Integer - whole number 
- Float - decimal number 
- Boolean - true / false 
- Char - single character 
- String - multiple characters 

Computers store data as binary using switches because a switch is either on or off so is 0 or 1 

Hexadecimal (0x) is easier to read / write than binary and represents 4 bits so is shorter 
Numbers 10 - 15 represented as A - F 

## - Binary Arithmetic 

Sign and magnitude is when the MSB (most significant bit) determines if the value is negative 
S&M range is -127 to 127 (two values for 0) 

2's Compliment is an overflow of 1s minus the positive of the value 
Hold rightmost 1and flip all to the left 
2's Complement range is -128 to 127 
![[]] S&M vs 2comp 

Addition and subtraction done with 2's complement 
Subtraction is addition of the 2's complement 
If answer has endless 1s then it is negative and additional 1s can be ignored 

Mantissa - Exponent form is a way of writing a wider range of binary values 
Where value = $M \times 2 ^ E$ 
Binary point always after MSB 
Normalised means first 2 bits either 10 or 01 
Normalised gives highest level of precision 
![[]] ME form

Logical shifts represent binary division / multiplication 

Bit masks can be with AND, OR or XOR 
Bit masks compare a binary value 2 bits at a time and create a new value based on the mask 
e.g. 01101000 with XOR masking of 11010110 is 10110110
