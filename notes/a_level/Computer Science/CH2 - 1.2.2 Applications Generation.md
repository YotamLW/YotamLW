#Computer-Science 

## - Software 

Applications are a type of software made for the user 
**Application** software : 
- Database - storing information 
- Word Processor - writing documents e.g. for businesses 
- Web browser - allows access to internet 
- Graphics manipulation - creating or editing images e.g. paint 

**Utility** software is a type of systems software made for the machine 
Used to manage, maintain and optimise a computer system e.g. OS, hardware 
Utility software : 
- Disk defragmenter - reorganises a magnetic hard disk 
- File management - allows logical file structure to be changed, e.g. file explorer 
- Device driver - allows different hardware to connect to the OS 
- System clean-up - allows managing / wiping of memory 
- Security - ensures no malicious programs are running e.g. windows defender 

## - Open vs Closed source 

Open & closed source refers to the licensing and availability of a program's source code 

**Open Source** : 
- Source code must be provided along with software 
- Often free / low cost 
- Anyone can modify the code and publish modified version 
- Community or third party driven 
- Published modified software must also be open source 
- Often less support and updates 

**Closed Source** : 
- Source code not available 
- May require purchase / subscription so expensive 
- Restrictions on code use and modification 
- Cannot be resold and modified outside legislative rules 
- Often more support and more frequent updates 
- Creator holds copyright for source code 

## - Translators 

**Translators** translate between types of code e.g. Assembly code to Machine code 
Input : source code 
Output : object code 

**Compiler** : 
- Translates code upon compilation into a saved file 
- Creates object / machine code for specific CPU architecture 
- Only needs to be compiled once 
- Executes faster once compiled 
- Slower feedback loop for developing 
- Harder to reverse engineer - useful for closed source software 

**Interpreter** : 
- Translates code line by line at run time 
- Source code run on virtual machine so functions on many different CPU architectures 
- Compiles each time run, often line by line 
- Executes slower 
- Quicker feedback loop so more useful for developers 

**Assembler** : 
- Translates assembly language into machine code 
- One line of source code -> one line of object code 
- Works the same as a compiler 

## - Stages of Compilation 

There are four stages to compilation : 
Lexical Analysis -> Syntax Analysis -> Code Generation -> Code optimisation 
The input / output for each respective stage : 
Source code -> Symbol Table -> Abstract Syntax Tree -> Object code -> Optimised code 

**Lexical Analysis** : 
- Removes comments and whitespaces 
- Simple error checking e.g. illegal identifiers 
- Source code (e.g. keywords & variables) turned into different types of tokens 
- Symbol table implemented as hash table using tokens 

**Syntax Analysis** : 
- Checks if syntax is valid using syntax diagrams 
- If error detected compilation will stop and error will be flagged 
- Checks if tokens from symbol table are in a valid order 
- Creates an abstract syntax tree out of tokens 

**Code Generation** : 
- Code is turned into object code using translator 
- Ensures tokens are correctly converted into machine code and follow abstract syntax tree 

**Code Optimisation** : 
- Removes redundant / repeated code 
- Rearranges code for efficiency 
- Optimises loops 
- Aim is to have faster code that takes less memory 
- Can create unexpected bugs 

## - Libraries 

A library is a collection of pre-written code e.g. a 3rd party program 
Programmer does not need to recode basic functions 
Can be loaded and run whenever required and for multiple programs at once 
More likely to be error free 
Less customisable and understandable than own code 

At compilation : A **linker** is used to combine libraries and code into one machine code file 

At run : A **loader** copies machine code of file and linked libraries into memory 

A linker may also add a pointer to the external library to the compiled code
