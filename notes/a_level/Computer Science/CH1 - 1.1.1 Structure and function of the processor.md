#Computer-Science 
## - Core components of Processor 

**Central Processing Uni**t (CPU) / Processor : 
- Control Unit - manages FDE cycle
- Manages Busses 
- ALU 
- Registers 

**Arithmetic Logic Unit** (ALU) : 
- Logic Operations (AND, OR, XOR etc.) 
- Bit shifts 
- Bit masks 
- Simple calculation (ADD, SUB, MULT etc.) 

## - Buses 

A bus is a set of parallel wires 
**System bus** is the control bus, data bus & address bus 
Control Bus : 
- bidirectional 
- sends commands and manages buses 
- keeps processor timing 
- prevents collisions 
Data Bus : 
- bidirectional 
- moves data and instructions 
Address Bus : 
- unidirectional (processor -> hardware) 
- transmits memory addresses

## - Processor Registers 

**Processor Registers** - ACC, PC, CIR, MAR, MDR 
Accumulator (ACC) - stores current result of operations 
Program Counter (PC) - holds address of next instruction 
Current Instruction Register (CIR) - holds current instruction and divides into opcode & operand 
Memory Address Register (MAR) - holds memory address for reading / writing 
Memory Data Register (MDR) - stores data for reading / writing 
![[1.1.1b]] 

## - FDE cycle 

**Fetch Decode Execute** (FDE) cycle is repeated by the processor. 
Fetch : 
- Address of next instruction copied from PC to MAR 
- Instruction of that address copied to MDR 
- PC is incremented to next address 
- MDR copied to CIR 
Decode: 
- Instruction in CIR split into opcode & operand 
- **Opcode** is the type of instruction 
- **Operand** is either an address, actual data or data for ALU 
Execute: 
- Instruction / opcode carried out on operand 
![[1.1.1c]]

## - Assembly language 

Assembly language uses these addresses to execute functions 
e.g. the function ADD : 
- uses MAR to access address given 
- uses MDR as data from address is copied to it 
- uses ACC to copy data onto 

## - CPU Performance 

Factors that affect processor speed are : 
**Clock Speed** : 
- Clock speed is how many times a second (Hz) the system clock sends pulses 
- Higher clock speed means more instructions / processes can be done per second as these are limited to each clock cycle 
- Overclocked may put more wear on processors 
**Core Number** : 
- Instructions can be processed simultaneously 
- Software may not be able to take advantage though 
**Amount & Type of Cache** : 
- Useful for storing common / repeated instructions 
- Less time to read & write data 
- Very fast, physically closer to processor 
- Very small and expensive 
**Pipelining** : 
- Reduces CPU inactivity by streamlining instructions 
- Especially useful for GPUs with simpler instructions 

## - Computer Architectures 

**Von Neumann** : 
- Shared memory for data and instructions 
- Same address & data buses 
- General purpose computers 
- Data may be misinterpreted as an instruction 

**Harvard** : 
- Separate memory for data and instructions 
- Separate address & data buses 
- Specific purpose computers e.g. washing machine 

Contemporary (modern) computers : 
- Harvard used for cache, Von Neumann used for RAM 
- Multiple cores 
- Co-processors e.g. GPU 
- Pipelining 
- Mix of RISC and CISC
