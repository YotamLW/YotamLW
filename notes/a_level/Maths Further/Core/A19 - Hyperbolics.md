Even functions are symmetrical about the y-axis so $f(x) = f(-x)$ 
Odd functions have rotation of order 2 about the origin so $f(x) = -f(-x)$ 
$$ e^x = \frac{e^x + e^{-x}}{2} + \frac{e^x - e^{-x}}{2} $$Where $\frac{e^x + e^{-x}}{2}$ is an even function and $\frac{e^x - e^{-x}}{2}$ is an odd function 

$$ \cosh(x) = \frac{e^x + e^{-x}}{2} \;\;\;\; \sinh(x) \frac{e^x - e^{-x}}{2} \;\;\;\; \cosh(x) + \sinh(x) = e^x$$
tanh is simply $\frac{\sinh(x)}{\cosh(x)}$

- $\cosh^2(x) - \sinh^2(x) = 1$ 
- $\DeclareMathOperator{\sech}{sech} \sech^2(x) + \tanh^2(x) = 1$ 
- $\DeclareMathOperator{\cosech}{cosech} \coth^2(x) - \cosech^2(x) = 1$
