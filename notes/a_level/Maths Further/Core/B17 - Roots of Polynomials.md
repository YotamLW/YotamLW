For roots $\alpha, \beta$ : $\sum \alpha = \alpha + \beta$ and $\sum \alpha \beta = \alpha \beta$ 
For roots $\alpha, \beta, \gamma$ : $\sum \alpha = \alpha + \beta + \gamma$ and $\sum \alpha \beta = \alpha \beta + \alpha \gamma + \beta \gamma$ and $\sum \alpha \beta \gamma = \alpha \beta \gamma$ 
etc. 

For a polynomial $a x^n + b x^{n-1} + c x^{n-2} + d x^{n-3} + ...$ who's roots are $\alpha, \beta, \gamma ...$ 
$\sum \alpha = -\frac{b}{a}$, $\sum \alpha \beta = \frac{c}{a}$, $\sum \alpha \beta \gamma = -\frac{d}{a}$, $\sum \alpha \beta \gamma \delta = \frac{e}{a}$ etc. 

If a new equation (in terms of $w$) has roots $2 \alpha + 1, 2 \beta + 1, 2 \gamma + 1 ...$ 
Then $w = 2x + 1$ so substitute $x = \frac{w - 1}{2}$ or find coefficients using new roots 
If $f(x)$ has the root $\alpha$ then $f(\frac{x - 1}{2})$ has the root $2 \alpha + 1$
