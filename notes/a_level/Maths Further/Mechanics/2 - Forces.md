Thrust is the same as compression 

Friction $F\leq\mu R$ where $R$ is normal reaction force 
Friction acts against motion and if an object is moving / about to move then $F=\mu R$ 
An object inclined on a slope of angle $\alpha$ is on the verge of slipping if $\mu=\tan\alpha$ : 
![[friction]] 

A particle is in equilibrium only if RF = 0 
A rigid body is in equilibrium only if RF = 0 and the sum of moments is 0 
A couple is a pair of forces in opposite direction such that RF = 0 but there is a resultant moment
