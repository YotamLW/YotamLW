Dimensions : 
- Mass - M 
- Length - L 
- Time - T 

Some quantities e.g. angles, ratios etc are dimensionless 

To convert between units, replace unit symbol with its equivalent in the other unit 
e.g. $1\,kg=2.2\,lbs$ so $10\,kg=10\,(2.2\,lbs)=22\,lbs$ 
e.g. $1\,hr=3600\,s$ so $5\,kg\,s^{-1}=5\,(2.2\,lbs)\,(\frac{1}{3600}\,hr)^{-1}=11\times 3600\,lbs\,hr^{-1}$ 

Can use dimensional analysis to check if a relationship is consistent on a base level 
Can use dimensional analysis to find indices of elements in a proposed formula
