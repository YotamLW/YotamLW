## Mappings 

A function is a mapping from the domain to the range 
- Domain - The set of possible inputs 
- Range - The set that covers exclusively all possible outputs 

Functions are either one-one or many-one : 
- One-to-one - One item in the domain maps to one item in the co-domain e.g. $y = x$ 
- Many-to-one - Multiple items in the domain map to one item in the co-domain e.g. $y = x^2$ 

A function is only well defined if every item of it's domain produces an output 
## Composite Functions 

The composite function $gf(x)$ means $f(x)$ followed by $g(x)$ 
For $gf(x)$, the domain of $g(x)$ is restricted to the range of $f(x)$ 
For $gf(x)$, the domain of $f(x)$ should be adjusted to provide a suitable domain for $g(x)$ 

## Inverse Functions 

An inverse function $f^{-1}(x)$ is one where $f^{-1}f(x) = ff^{-1}(x) = x$ 
To find the inverse function, rearrange function to be $x$ in terms of $f(x)$ 
The domain of an inverse function is the original function's range 
An inverse function is only well defined if the original is one-to-one 
The graph of an inverse function is the graph of the original function reflected in the line $y = x$ 

## Modulus Function 

The modulus function makes things positive, $|x| = \sqrt{x^2}$ 
For inequalities, use $f(x)$ and $-f(x)$ with limited domains 
Drawing the function can be useful to determine when to use $f(x)$ or $-f(x)$
