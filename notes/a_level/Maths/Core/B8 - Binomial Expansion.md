Binomial expansions has coefficients from Pascal's triangle 
$^nC_r$ gives the coefficients where $^nC_0 = ^nC_n = 1$ 
$(a + bx)^n = {^nC_0} \; a^n + {^nC_1} \; a^{n-1} b x + {^nC_2} \; a^{n-2} b^2 x^2$ 

Formula for $(1 + x)^k$ where $k$ is a rational number : $$ 1 + kx + \frac{k (k-1)}{2!} x^2 + \frac{k (k-1) (k-2)}{3!} x^3 + ...$$
Useful for approximating when $k$ is not a positive integer if $|x| < 1$ 
$(a + bx)^k = a^k (1 + \frac{b}{a}x)^k$ 
In this case can approximate if $|\frac{b}{a}x| < 1$
