## Graph Transformations

For a function $\mathcal{f}(x)$ mapped to $a f(bx + c) + d$ : 
The order of transformations is $cbad$ 
- $a$ stretches the graph parallel to the y-axis by scale factor $a$ 
- $b$ stretches the graph parallel to the x-axis by scale factor $\frac{1}{b}$ 
- $c$ translates the graph horizontally by $-c$ 
- $d$ translates the graph vertically by $d$ 
Translations can be stated as vectors 
## Graph Sketching 

Check for x intercepts when $y = 0$ 
Check for y intercepts when $x = 0$ 
Check what happens to $f(x)$ when $x \rightarrow \pm \infty$ 
Turning points when $\frac{dy}{dx} = 0$ 

Vertical asymptotes when denominator is 0 
Horizontal asymptotes if $f(x)$ tends to a constant as $x \rightarrow \infty$ 

Can be useful to split up top-heavy fractions 
e.g. $y = \frac{x^2 - 2}{x - 1} = x + 1 - \frac{1}{x-1}$ so as $x \rightarrow \pm \infty$ then $f(x) \rightarrow x + 1$
