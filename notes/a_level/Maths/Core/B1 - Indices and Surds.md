Square root of a surd e.g. $\sqrt{3 + 2 \sqrt{2}}$ : 
$\sqrt{3 + 2 \sqrt{2}} = \sqrt{a} + \sqrt{b}$ 
$3 + 2 \sqrt{2} = (\sqrt{a} + \sqrt{b})^2$ 
$3 + 2 \sqrt{2} = a + b + 2 \sqrt{ab}$ 
$a + b = 3$ and $2 \sqrt{ab} = 2 \sqrt{2}$ 
Solving simultaneously, $a = 1$ and $b = 2$ 
So $\sqrt{3 + 2 \sqrt{2}} = \sqrt{1} + \sqrt{2} = 1 + \sqrt{2}$
