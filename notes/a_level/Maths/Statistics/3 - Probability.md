#Mathematics #Statistics 

The probability of event $A$ is denoted $P(A)$ 
The complementary event $A'$ is the event not-$A$ such that $P(A)+P(A')=1$ 
Expected frequency is $n\times P(A)$ where $n$ is number of trials

Mutually exclusive events are events that cannot occur simultaneously e.g. it is day or it is night 
For mutually exclusive events, $P(A\cup B)=P(A)+P(B)$ and $P(A\cap B)=0$ 

For two events : $P(A\cup B)=P(A)+P(B)-P(A\cap B)$ and $P(A|B)=\frac{P(A\cap B)}{P(B)}$ 

Independent events are events which do not affect each other 
For independent events, $P(A\cap B)=P(A)\times P(B)$ so $P(A|B)=P(A)$ 
$P(B|A)=P(B)\iff$ $A$ and $B$ are independent
