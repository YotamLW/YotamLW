## Data Presentation 

Types of data : 
- Discrete - Data with specific values and gaps between 
- Continuous - Data which can take a range of values - no gaps 
- Categorical - Data that falls into labelled groups 
- Ranked - Data ordered by a rank 

Data presentation methods : 
- Bar charts - bars where height = frequency 
- Dot plot - bars of dots where number of dots = frequency 
- Histogram - bars with no gaps where width $\times$ height = frequency and width is the range 
- Vertical line chart - bar chart 
- Pie chart - pizza 
- Stem-and-leaf diagram - Stem is 10s digits, leaves are 1s digits 
- Box and whisker diagram (box plot) - box to represent interquartile range, whiskers for range 
- Frequency chart - bar chart with no gaps 

Histograms : 
- Area of each bar is proportional to frequency 
- Width of bars is range of frequency 
- Height of bars is frequency density 

Cumulative frequency diagram : 
- Cumulative frequency on the y-axis 
- Measured data (e.g. length) on the x-axis 

Type of frequency distributions : 
- Symmetrical - symmetrical 
- Unimodal - only one peak 
- Bimodal - multiple peaks 
- Skewed - not symmetric 
- Positively skewed - More data on lower end with a long tail to the right 
- Negatively skewed - More data on the upper end with a long tail to the left 

Diagrams of unbiased samples become more representative of theoretical probability distributions with increasing sample size 

## Bivariate Data 

Scatter diagrams are points with two variables  
Association means there is a relationship between two variables ; changes in one affects the other 
Correlation describes the linear relationship between the two variables 
Correlation does not mean causation 
Types of correlation : 
![[correlation]] 

A best fit model is an equation to represent the relationship between two variables 
A regression line is a straight line of best fit that represents the relationship between two variables 
Interpolation is the use of the best fit model to estimate values within the given data range 
Extrapolation is the use of the best fit model to estimate values outside of the given data range 

A scatter diagram with obvious clusters may be showing distinct sections of a population 
Outliers are items which are inconsistent with the rest / majority of the data 
Outliers should be spotted by eye 

Bivariate data consists of two variables for each item of a sample 

## Data measures 

Measures of central tendency : 
- Median - midpoint of ordered data (useful when data is skewed, has outliers or is ranked) 
- Mode - most common data value (useful for categorical data) 
- Mean - $\bar{x}=\frac{1}{n}\sum x$ (useful for symmetrical data) 
- Midrange - $\frac{1}{2}$(maximum value + minimum value) (useful for quick rough estimate) 

Measures of spread : 
- Range - highest value - lowest value 
- Percentile - indicates how many values are below a given value as a percentage 
- Quartiles - splits data into 4 sections 
- Interquartile range - upper quartile - lower quartile (middle 50% so outliers have less effect) 

Sample variance $s^2=\frac{S_{xx}}{n-1}$ where $S_{xx}=\sum{(x_i-\bar{x})^2}$ 
Sample standard deviation $s=\sqrt{\text{variance}}$ 
Use $s$ and $s^2$ NOT $\sigma$ and $\sigma^2$ from calculator 
Variance measures how much data points deviate from the mean 
Standard deviation expresses deviation in the same units as the original data 
Greater standard deviation indicates a greater variation / spread of the data 

An outlier is an item which is inconsistent with the rest of the data 
An outlier is a data value that is either : 
- At least 2 standard deviations from the mean 
- At least 1.5 $\times$ IQR (interquartile range) beyond the nearer quartile
