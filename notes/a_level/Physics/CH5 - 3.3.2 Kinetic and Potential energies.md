#Physics #Energy 

Kinetic Energy of an object : $KE = \frac{1}{2}mv^2$ 
Gravitation Potential Energy of an object in a uniform field : $GPE = mgh$ 
KE can be converted to GPE and back in systems 
e.g. when an object falls, GPE is converted into KE 

Derivation of KE equation : 
- $v^2 = u^2 + 2as$ and u = 0 so $s = \frac{v^2}{2a}$ 
- $F = ma$ and $W = Fd$ so $W = ma \times d$ 
- $W = ma \times \frac{v^2}{2a} = \frac{1}{2}mv^2$ 

Derivation of GPE equation : 
- $F = ma$ so Weight = $mg$ 
- $W = Fd$ so $W = mgd = mgh$
