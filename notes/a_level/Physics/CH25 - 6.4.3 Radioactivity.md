#Physics #Nuclear 

Radioactive decay occurs randomly and spontaneously 
Radioactive decay is 

Alpha radiation : 
- Alpha particles ($\alpha$) are helium nuclei (2 protons, 2 neutrons) so have $+2e$ charge 
- Low penetration level (sheet of paper) 
- Short range (a few cm) 
- $^A_ZX\rightarrow^{A-4}_{Z-2}Y+^4_2He$ 

Beta radiation : 
- Beta particles ($\beta$) are electrons or positrons so have either $+e$ or $-e$ charge 
- Medium penetration (sheet of aluminium) 
- Medium range (a metre) 
- $^A_ZX\rightarrow^A_{Z+1}Y+^{\;\;0}_{-1}e+\bar{v}_e$ or $^A_ZX\rightarrow^A_{Z-1}Y+^{\;\;0}_{+1}e+v_e$ 

Gamma radiation : 
- Gamma rays ($\gamma$) are high-energy gamma photons and have no charge 
- High penetration (few cm of lead) 
- High range (more than 1 km) 
- $^A_ZX\rightarrow^A_ZX+\gamma$ 

Radiation absorption investigation : 
- Place a Geiger-Muller tube connected to a counter and record background radiation count rate 
- Place a radioactive source a distance away from the tube 
- Place the absorber between the source and the tube and record count rate 
- Corrected count rate is measured count rate - background count rate 

The activity of a source $A=\lambda N$ where $\lambda$ is the isotope's decay constant and has units $s^{-1}$ 
$A=A_0\,e^{-\lambda t}$ where $A$ is activity in becquerels ($Bq$) 
$N=N_0\,e^{-\lambda t}$ where $N$ is number of undecayed nuclei 

Radioactive decay can be modelled using dice thrown 
Every time a six is rolled, remove the die and count it as a nuclei that has decayed 

Half life $t_{1/2}=\frac{\ln(2)}{\lambda}$ 
Derivation : 
- $\frac{1}{2}A_0=A_0\,e^{-\lambda t_{1/2}}$ 
- $\ln(\frac{1}{2})=-\lambda t_{1/2}$ 
- $t_{1/2}=\frac{\ln(2)}{\lambda}$ 

Investigation to determine half life : 
- Determine background count rate using GM tube 
- Use a short-life radioactive isotope e.g. protactinium 
- Measure count rate ($A$) for several seconds (e.g. 10) at longer intervals (e.g. 1 minute) 
- $A=A_0\,e^{-\lambda t}$ so $\ln(A)=\ln(A_0)-\lambda t$ 
- Plot a graph of $\ln(A)$ on $t$ (where $t$ is each time interval) 
- Find the gradient which will be equal to $-\lambda$ 
- Use this in the half life equation to determine half life 

Can model radioactive decay using the equation $\frac{\Delta N}{\Delta t}=-\lambda N$ 
How to model decay on a spreadsheet : 
- Start with $N_0$ particles and a time interval $t$ where $t<t_{1/2}$ e.g. $t=\frac{1}{10}t_{1/2}$ 
- $\Delta N$ is the number of nuclei decreasing so $\Delta N=N\times\lambda\Delta t$ 
- So now $N_{\text{new}}=N_{\text{old}}-\Delta N$ and repeat 

Radioactive dating is when the age of something can be determined based on how much of the original radioactive isotope is still present 
Carbon dating is when the isotope carbon-14 is used in dead organic material e.g. fossils
