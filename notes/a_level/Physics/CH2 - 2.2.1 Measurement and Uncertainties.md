#Physics #Fundamentals

Error is the difference between obtained result and the correct result 
All errors are either random or systematic 
Random errors are caused by things like people making mistakes or random events 
Systematic error is error that is constant or scales with values in the experiment 
An example is zero error, where scales are not set to 0 before weighing 

Precision means measurements / results are close to each other 
Accuracy means measurements / results are close to the true measurement / result 

Absolute uncertainty is written as : value $\pm$ absolute uncertainty 
e.g. for a value of $90 \pm 3$ the absolute uncertainty is 3 
Absolute uncertainty should be written to the same number of d.p. as the value 
Percentage uncertainty is $\left( \frac{\text{absolute uncertainty}}{\text{measured value}} \right) \times 100$ 

Absolute uncertainty in repeated data is half of its range 
Absolute uncertainty in a measurement is the resolution of the measuring equipment 
Resolution of a mechanical device is it's smallest division 
Resolution of a digital device is it's last significant digit 

When adding / subtracting data, add the absolute uncertainties 
When multiplying / dividing data, add the percentage uncertainties 
When raising data to powers, multiply percentage uncertainty by the power 

Absolute uncertainty in a graph is the difference in gradient
