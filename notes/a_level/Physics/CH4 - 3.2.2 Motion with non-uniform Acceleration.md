#Physics #Force 

Drag is a frictional force experienced by an object moving through a fluid 
Drag is often proportional to the square of speed 
Factors affecting drag in a fluid : 
- Speed of object 
- Cross-sectional area of object 
- Shape of the object 
- Texture of the object 
- Density of fluid 
- Viscosity of fluid

Terminal velocity occurs at the speed of an object where drag = weight force 
This means there is no resultant force so no acceleration so the object moves at constant speed 

Experiment to determine terminal velocity through fluid : 
- Fill test tube with fluid 
- Record object falling through fluid 
- Find distance travelled in set time intervals and find when distance travelled is the same 
- Calculate speed at this point
