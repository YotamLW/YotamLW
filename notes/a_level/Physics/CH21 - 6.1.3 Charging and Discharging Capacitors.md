Equations for discharging and charging a capacitor are modelled by exponential decay $x = x_0 e^{- \frac{t}{RC}}$ 

$I = \frac{V}{R}$ so $I = \frac{Q}{RC}$ 
In a discharging capacitor, charge decreases, so $I = - \frac{\Delta Q}{\Delta t}$ 
Therefore $\frac{\Delta Q}{\Delta t} = - \frac{Q}{RC}$ so $\Delta Q = Q \times - \frac{\Delta t}{RC}$ 
This iterative equation can be used to plot charge over time on a table 
$Q = Q_0 e^{- \frac{t}{RC}}$ 

When charging a capacitor : 
- $V = V_0 (1 - e^{- \frac{t}{RC}})$ 
- $I = I_0 e^{- \frac{t}{RC}}$ 
- $Q = Q_0 e^{- \frac{t}{RC}}$ 
When discharging a capacitor : 
- $V = V_0 e^{- \frac{t}{RC}}$ 
- $I = I_0 e^{- \frac{t}{RC}}$ 
- $Q = Q_0 e^{- \frac{t}{RC}}$

An exponential decay graph has a constant-ratio property 
This means that a value decreases by the same percentage in equal intervals of time 

When $t = RC = \tau$,  $e^{- \frac{t}{RC}} = e^{-1} \approx 0.37$ 
so $x \approx 0.37 x_0$ or $x \approx 0.63 x_0$ 

$V = V_0 e^{- \frac{t}{RC}}$ so $ln(V) = ln(V_0) - t \frac{1}{RC}$ 
$ln(V)$ on $t$ can be plotted as a straight line with y-intercept $V_0$ and gradient $- \frac{1}{RC}$
