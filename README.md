# Information

To navigate the website as intended go to https://yotamlw.com <br>
Currently it is possible to navigate locally by just opening the raw html files, but they will not be formatted or have anything but text. This is because I use `fetch()` to load html code onto one `index.html` file because I am actively changing page layout, style and source files. If you want to view the formatted files locally, you can either start a local live server (on `/website/index.html`) with an IDE (I use the live server plugin on vscode and barret-ruth/live-server on neovim) or paste the html text into the respective index.html (removing the page-loading code and wrapping the text in `<div id="pageContent"></div>` for formatting).
