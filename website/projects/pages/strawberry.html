1 Introduction

This project is about building an app that plays local audio (music) files. My goals will be listed in depth later but basically I am aiming for a minimal GUI with typical music-playing functionalities (e.g. shuffle, looping, volume etc.) and easily customisable organisation (e.g. albums, artists). I will be building this app specifically for my operating system of arch-linux. I have basically no experience with app development so this will be a very informal project and I will try to explain what I do and why. This project is titled phase 1 because if I finish this I will try to make a physical device to run the app and play music while out and about (an MP3 player).

1.1 Obtaining Music

The main ways of obtaining music files is either by digitising a CD, buying the music online (e.g. amazon music) or by downloading copyright-free music online. To avoid any copyright issues I have downloaded a selection of copyright-free classical music recordings using yt-dlp and ffmpeg. These packages make it easier to download and convert music. I decided to use opus file format because it takes less space and I'm building from scratch so there shouldn't be any compatibility issues. I downloaded the music using the yt-dlp <tags> <URL> command with the following tags (separated by spaces) : -x which only downloads audio; --audio-format opus; --audio-quality 128K which is the bitrate; --ppa "ExtractAudio+ffmpeg_o:-acodec libopus -af loudnorm" which is an ffmpeg command to normalise audio (long because it forces recompilation to opus as yt-dlp preferes to copy a file if it exists which messes up the audio normalisation). Also I had to write the tags out individually because I wasted far too long trying to get stylised code to wrap nicely on OpTeX and now here. I also messed around with downloading to specific files and auto-inserting metadata but decided it would be better to make a simple editor as part of the app.

1.2 File Formatting

The format for file names doesn't really matter as I plan to read metadata to identify songs details in the app. For now, I am only interested in a songs title, artist, album and year (of release). For editing file metadata I used the package opustags where I manually entered tags. An example command used was opustags -i -D -a "TITLE=La Folia" -a "ARTIST=Vivaldi" -a "DATE=1705" VIV01.opus. In the future I will probably write a script with a UI in the app to make assigning song details easier through batch selection (e.g. artist or album).

The code below was used to test simple file playback.

At the top, the use lines are importing library commands to use. The rodio library adds audio handling commands. The main() function is called by default when the file is run. Line 06 tries to set up audio on the default device playback. I also learned that having _stream is for variables that need to be kept but not used, as if dropped audio would not play and if not marked with _ Rust would give a warning as it is not used directly. Line 08 declares the sink which is where the audio goes to be played. The & prefix for variables only lets the function look at the variable. If the variables was passed as is it would be moved from the current scope to the function scope and be inaccessible outside afterwards. Line 12 decodes the audio file. BufReader makes files process in chunks to reduce system calls so saves on resources. The unwrap() method was used on most commands temporarily which basically does if (error) {crash} else {return value}.

01 use rodio::{Decoder, DeviceSinkBuilder, Player};
02 use std::os::unix::net::UnixListener;
03 use std::io::{BufReader, BufRead};
04 use std::fs::File;
05 
06 const SOCKET_PATH: &str = "/tmp/music-daemon.sock";
07 const MUSIC_PATH: &str = "/home/bob/Music/Songs/";
08 
09 fn main () {
10   
11   let stream_handle = DeviceSinkBuilder::open_default_sink().expect("audio stream failed");
12   let player = Player::connect_new(stream_handle.mixer());
13 
14   let _ = std::fs::remove_file(SOCKET_PATH);
15   let listener = UnixListener::bind(SOCKET_PATH).unwrap();
16   println!("Daemon listening at {}", SOCKET_PATH);
17 
18   for stream in listener.incoming() {
19     let stream = stream.unwrap();
20     let reader = BufReader::new(stream);
21     for line in reader.lines() {
22       let line = line.unwrap();
23       handle_command(&line, &player);
24     }
25   }
26 
27 }
28 
29 fn handle_command (line: &str, player: &Player) {
30 
31   let mut parts = line.splitn(2, ' ');
32   let command = parts.next().unwrap_or("");
33   let filename = parts.next().unwrap_or("");
34   let arg = format!("{}{}", MUSIC_PATH, filename);
35   
36   match command {
37 
38     "play" => {
39       match File::open(&arg) {
40         Ok(file) => {
41           match Decoder::new(BufReader::new(file)) {
42             Ok(source) => {
43               player.stop();
44               player.append(source);
45               player.play();
46               println!("Playing {}", arg);
47             }
48             Err(e) => println!("Failed to decode {} : {}", arg, e),
49           }
50         }
51         Err(e) => println!("Failed to load {} : {}", arg, e),
52       }
53     }
54 
55     "stop" => {
56       player.stop();
57     }
58 
59     _ => println!("Invalid command : {}", command),
60 
61   }
62 
63 }
