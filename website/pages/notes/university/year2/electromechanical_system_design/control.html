Control

A control system is a combination of processes to transform an input signal of a desired output into the desired output. Functions are often used to represent inputs, e.g. a step function. Steady state is the stable long-term output given an input. Transient response is the characteristic of the output before it reaches steady state. Steady state error is the deviation of the output from the desired output. Open loop system translates input directly and cannot respond to disturbances (e.g. car pedal, manual control). Closed loop system (feedback control) has its output fed back into input in certain ways to callibrate the system, so can compensate for disturbance.

A standard diagram for analysing feedback control systems is shown below, including: r (reference of desired output), e (error signal), u (control signal), d (disturbance signal) and y (process output). The summation unit just finds the error difference, the controller produces an appropriate signal based on the error which is fed into the system. For example, desired output is changed, so there is a difference between current state and desired (as picked up by sensor), the controller calculates how to use actuators on the system to approach the desired goal and adapts based on disturbance. Sensors are assumed to be perfect in this module.

Modelling from first principles is derriving equations of system response. Data-driven modelling is inferring the equation by brute force (so statistically sound). Reference tracking is trying to match a desired output. Disturbance rejections is trying to maintain an output.

Laplace transforms convert differential equations in the time domain into algebraic equations in the laplace domain. Tranforming to and from laplace is quite complicated (apparently) so a table of common transforms is used in this module. A unit step function is 0 for $t\leq0$ and 1 for $t\geq0$. Step function is a unit function with a constant coefficient. Partial fractions is very common to make multiple fractions that can be converted from the Laplace domain.
