Fundamentals

This topic assumes knowledge of negative numbers, equations, addition and multiplication.

Variables

Numbers can be represented by symbols (mainly letters) as placeholders. Constants are placeholders for numbers that are always the same, for example $\pi$ is used as a constant for the number $3.14...$. Variables are placeholders for numbers that are not yet known, so equations and calculations can be done for sets of inputs. Variables that are placeholders for a combination of numbers, operations and placeholders are called functions, for example the area of a circle $A=\pi\times r\times r$, where $r$ is the radius variable.

Functions

An example of a simple function is $f(x)=x+1$, where $f$ is the function variable / identifier, the $x$ in the brackets states the function's input and the maths after the equals sign defines what to do with the input. Any symbol can represent a function (because it's just a dependent variable) but it is conventional to use letters around the middle of the alphabet such as $f()$, $g()$ and $h()$. When there are many different functions a subscript is often used e.g. $f_1()$, $f_2()$, $f_3()$ etc. Functions with more than one input have them comma separated e.g. a function for adding two numbers is $f(x, y)=x+y$.

A set is a collection of numbers, for example a set $S$ containing the numbers 1, 2 and 4 is denoted as $S=\{1,2,4\}$. The set of real numbers is denoted $\mathbb R$. A domain of a function is the set of inputs allowed to enter the function. The domain is assumed as the broadest set for the given context (e.g. all real numbers), but if a more limited domain is needed then it is written after the function with braces e.g. $f(x)=x+1\;\{x>0\}$. The range of a function is the set of all possible outputs given the domain, for example if the function $f(x)=x+1$ is given the domain $\{1,2,4\}$ the range would be $\{2,3,5\}$. Mapping is the process of converting an input into an output through a function. A function must also map every individual input to exactly one output. A one-to-one function is when every input has a unique output e.g. $f(x)=x$. A many-to-one function is one where many inputs can result in the same output e.g. $f(x)=1$ wehre every output is 1. One-to-many and many-to-may relationships are not functions because inputs may map to many outputs which contradicts the definition of a function. This can be overcome by limiting the range to exclude repeating areas.

Operations

An operation is some logical action performed with one or two numbers / variables, for example '1+2' is an addition operation between the numbers 1 and 2. All operations are functions. Most complex operations (involving more than two elements) can be broken down into a series of operations between two elements (binary operations). The order in which operations are applied affects the result. For example: doubling one then adding one is three; adding one to one then doubling that is four. Brackets isolate operations into groups. The contents of each bracket group should be evaluated before evaluating external operations. The previous example can be written as $(2\times1)+1$ and $2\times(1+1)$, where the brackets show which step is carried out first. Variables are essentially bracket groups so they always need to be substituted into a bracket group; if $a=3-2$ then $4\times a$ turns to $4\times(3-2)$ when substituting (in order to preserve order of operations). When brackets groups are written next to each other such as $(4)(1+1)$, it means they should be multiplied, so it is really $(4)\times(1+1)$.

An arbitrary binary operation is denoted using $\circ$ as $x\circ y$. A binary operation $\circ$ on a set $S$ (or a set $S$ under a binary operation $\circ$) is a rule which assigns to each ordered pair $x$ and $y$ (meaning order of $x$ and $y$ matters) in $S$ exactly one element $x\circ y$. This just means any combination of elements of the set can be used as inputs of this operation, and that they should only give one definite answer (to remain functions). This rule is denoted $(S,\circ)$, so for example addition on real numbers is $(\mathbb R,+)$. Another conventional format is $S^\circ$ (so $\mathbb R^+$ as per the previous example).

Inverse functions

Subtraction is the inverse operation of addition. This means if $a$ is added to $b$, then subtracting $a$ from the result should equal $b$, so $(b+a)-a=b$. Addition is also the inverse of subtraction, so $(b-a)+a=b$. Similarly, division is the inverse operation of multiplication (and vice versa), so $(b\times a)\div a=(b\div a)\times a=b$. A superscript on a base (e.g. $2^3$ where 2 is the base and 3 is the superscript) is called an exponent (or indice or power). What the exponent means is how many times you should multiply 1 by the base, for example $2^3$ means $1\times2\times2\times2$. For negative exponents, the inverse is used so 1 is divided by the base that many times, e.g. $2^{-1}$ is $1\div2$.
