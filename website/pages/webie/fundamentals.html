Fundamentals

Mathematics is a language used to suspend and manipulate the conversion of inputs to outputs.

Concept

A set is a collection of numbers. The contents of a set are declared within braces. Sets are often identified by capital letters of various fonts. A set containing the numbers 1, 2 and 4 is defined as $\{1,2,4\}$ and can be given an identifier $S$. The set of real numbers is denoted $\mathbb R$. An element is some abitrary number of a set (so is a variable).

Numbers can be represented by symbols as placeholders. Constants are placeholders for numbers that are always the same (for example, $\pi$ is used as a constant for the number $3.14\dots$). Variables are placeholders for numbers that are not yet known, or for an element of a set. This essentially "suspends" a process that converts an input to an output and allows it to be analysed and manipulated. Variables are always one character, but can be modified with subscripts and hats to be differentiated. A common example is $t_1,t_2,t_3$, where $t$ is used to represent time, and the subscript indicates different measurements of time, but the base character can remain the same for readability.

An operation is some logical action on a variable (unary) or between two variables (binary). An arbitrary binary operation is given the symbol $\circ$ (for example, an arbitrary binary operation on two variables $a$ and $b$ is written $a\circ b$). A domain is a set of numbers that act as inputs to an operation. All operations must be defined as being applied on a specific domain, and will only be valid for inputs within that domain (for example, standard addition is really "addition on the set of real numbers"). An operation $\circ$ on some set $S$ is denoted as $(S,\circ)$ or $S^\circ$. A range is the set of numbers that are the output of an operation.

An expression is a collection of numbers, variables and operators that represents something. An equation is two expressions defined as equal using an equals sign $=$ between them. A term is any part of an expression; it could be a single number / variable or the whole expression. Terms are often differentiated by operation symbols.

Commutativity is a porperty of binary operations, meaning that for any two elements $a$ and $b$, then $a\circ b=b\circ a$ (i.e. the order of the operands about the operator does not matter). An identity element of a binary operation is an element that when paired with any other element, will output that other element, so for any element $a$ and identity element $e$, $a\circ e=e\circ a=a$. Some operations may only have a right identity ($a\circ e=e$) or only a left identity.

Addition on the set of real numbers $\mathbb R^+$ is the intuitive combination of two elements to make one new element. The + symbol is used between the two numbers to be combined (for example, $2+3$ becomes $5$). This operation is commutative and the identity element is $0$.

Multiplication $\mathbb R^\times$ is a binary operation, where one element declares how many times the other should be added to the additive identity, $0$. The $\times$ symbol is used between the two elements. This operation is commutative and the identity element is $1$. The multiplication symbol is usually only drawn when multiplying two numbers; for numbers on variables or variables on variables, the symbols are placed next to each other ($5\times a$ is written as $5a$ and $a\times b$ is written as $ab$). It is conventional that numbers are to the left of variables. Coefficients are a number or variable that multiply another variable, conventionally on the left.

Exponentiation $(\mathbb R,a^b)$ is a binary operation with a base and exponent. The exponent is the superscripted element, which declares how many times the multiplicative identity $1$ should be multiplied by the base. This operation is not commutative, but it has a right identity element (the superscript) of $1$.

An inverse element is one that when paired with some element gives the identity element. For some element $a$ the inverse element is denoted $a^{-1}$ and $a\circ a^{-1}=a^{-1}\circ a=e$.

Equations

Functions

An example of a simple function is $f(x)=x+1$, where $f$ is the function variable / identifier, the $x$ in the brackets states the function's input and the expression after the equals sign defines what to do with the input. Any symbol can represent a function (because it's just a dependent variable) but it is conventional to use letters around the middle of the alphabet such as $f()$, $g()$ and $h()$. When there are many different functions a subscript is often used e.g. $f_1()$, $f_2()$, $f_3()$ etc. Functions with more than one input have them comma separated e.g. a function for adding two numbers is $f(x,y)=x+y$.

A set is a collection of numbers, for example a set $S$ containing the numbers 1, 2 and 4 is denoted as $S=\{1,2,4\}$. The set of real numbers is denoted $\mathbb R$. A domain of a function is the set of inputs allowed to enter the function. The domain is assumed as the broadest set for the given context (e.g. all real numbers), but if a more limited domain is needed then it is written after the function with braces e.g. $f(x)=x+1\;\{x>0\}$. The range of a function is the set of all possible outputs given the domain; for example, if the function $f(x)=x+1$ is given the domain $\{1,2,4\}$ the range would be $\{2,3,5\}$. Mapping is the process of converting an input into an output through a function. A function must also map every individual input to exactly one output. A one-to-one function is when every input has a unique output e.g. $f(x)=x$. A many-to-one function is one where many inputs can result in the same output e.g. $f(x)=1$ wehre every output is 1. One-to-many and many-to-may relationships are not functions because inputs may map to many outputs which contradicts the definition of a function. This can be overcome by limiting the domain of the function to avoid repeating values in the range. A good example is the square root function which will be mentioned further down.

Operations

An operation is some logical action performed with one or two numbers / variables, for example '1+2' is an addition operation between the numbers 1 and 2. All operations are functions. Most complex operations (involving more than two elements) can be broken down into a series of operations between two elements (binary operations). The order in which operations are applied affects the result. For example: doubling one then adding one is three; adding one to one then doubling that is four. Brackets isolate operations into groups. The contents of each bracket group should be evaluated before evaluating external operations. The previous example can be written as $(2\times1)+1$ and $2\times(1+1)$, where the brackets show which step is carried out first. Variables are essentially bracket groups so they always need to be substituted into a bracket group; if $a=3-2$ then $4\times a$ turns to $4\times(3-2)$ when substituting (in order to preserve order of operations). When brackets groups are written next to each other such as $(4)(1+1)$, it means they should be multiplied, so it is really $(4)\times(1+1)$.

An arbitrary binary operation is denoted using $\circ$ as $x\circ y$. A binary operation $\circ$ on a set $S$ (or a set $S$ under a binary operation $\circ$) is a rule which assigns to each ordered pair $x$ and $y$ (meaning order of $x$ and $y$ matters) in $S$ exactly one element $x\circ y$. This just means any combination of elements of the set can be used as inputs of this operation, and that they should only give one definite answer (to remain functions). This rule is denoted $(S,\circ)$, so for example addition on real numbers is $(\mathbb R,+)$. Another conventional format is $S^\circ$ (so $\mathbb R^+$ as per the previous example).

Inverse functions

Subtraction is the inverse operation of addition. This means if $a$ is added to $b$, then subtracting $a$ from the result should equal $b$, so $(b+a)-a=b$. Addition is also the inverse of subtraction, so $(b-a)+a=b$. Similarly, division is the inverse operation of multiplication (and vice versa), so $(b\times a)\div a=(b\div a)\times a=b$. A superscript on a base (e.g. $2^3$ where 2 is the base and 3 is the superscript) is called an exponent (or indice or power). What the exponent means is how many times you should multiply 1 by the base, for example $2^3$ means $1\times2\times2\times2$. For negative exponents, the inverse is used so 1 is divided by the base that many times, e.g. $2^{-1}$ is $1\div2$.
