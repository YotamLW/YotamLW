Use of LLMs

I use LLMs as a way of learning, meaning that I don't give it vague tasks to complete autonomously. With code, the LLM will often generate complete blocks of code automatically, but I never copy these blocks without understanding every line, because I enjoy coding the website is part of the fun in making it for me. Of course, the code currently on this website is very simple and general so it can't really be that original as it's all surface-level ball knowledge. How I try to use LLMs for coding is basically like a more centralised internet search engine and like asking a teacher questions; for example, asking how more special-case JavaScript mechanics function or what a new function I discovered does. For content, I always write up my own drafts first using what I remember and static sources I have first, then check if I have worded the topic appropriately with an LLM. I do not write in a linear way at all, usuallyting and changing the order of a sentence multiple times before ending it, then going over the entire paragraph again multiple times and changing the order of sentences (and same with paragraphs). This means I will use LLMs for judging sentences, paragraphs or even words I am unsure about at any point, as well as ask if it thinks I missed talking about anything. I never copy any sentences directly from LLMs, only occasional short phrases. Once I finalise a page and push it to the website sometimes I ask my friends to also review it.
