DWM

X11 and Wayland are two things needed for graphical display which I could not find coherent explanations of, so I will learn it later.

DWM is a window manager, windows being the bounding box that graphical apps occupy. This is often what people confuse with an operating system, because a window manager is what you can actually see (apart from the tty consoles). DWM runs on X11, so you will need to install at least xorg-server xorg-init xorg-xsetroot xorg-xset. If you use an nvidia graphics card, you should install nvidia-open nvidia-utils nvidia-settings (or nvidia instead of open for cards not GTX 16xx, RTX 20xx or newer, double check).
